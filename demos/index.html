Apps for local businesses (Track A)

  • site-kit

    Four static site templates (restaurant, barber, dentist, gym) in French and Arabic. See above.

    Folder site-kit · npm run build && npm run serve → http://localhost:3100

  • qr-menu (Tawla)

    QR-code restaurant menu; diners send the order to the restaurant's WhatsApp.

    Folder qr-menu · npm install && npm run dev → http://localhost:3110

  • booking-page

    Salon appointment booking with free time slots and WhatsApp confirmation; admin at /admin.

    Folder booking-page · npm install && npm run dev → http://localhost:3120

SaaS tools (Track B)

  • invoice-ma (Facture.ma)

    Invoices for Moroccan auto-entrepreneurs with ICE/IF, TVA and PDF.

    Folder invoice-ma · npm install && npm run dev → http://localhost:3200

  • form-backend (Postbox)

    Form endpoint for static sites: submissions stored, dashboard and CSV export.

    Folder form-backend · npm install && npm run dev → http://localhost:3210

  • waitlist-kit

    Embeddable waitlist widget with a referral queue.

    Folder waitlist-kit · npm install && npm run dev → http://localhost:3220

API and infrastructure (Track C)

  • og-image-api

    API that returns 1200x630 social preview images, with API keys and usage limits.

    Folder og-image-api · npm install && npm run dev → http://localhost:3300

  • cron-hooks

    Scheduled webhooks as a service with retries and delivery log. API only; needs Postgres (see its README) and ../pg-jobq.

    Folder cron-hooks · see README → http://localhost:3340

  • status-page

    Uptime checks plus a public status page per customer.

    Folder status-page · npm install && npm run dev → http://localhost:3350
