# Delivery and handover checklist

Use one copy per client. Do not mark "go live" until every box in sections 1 to 3 is ticked.

## 1. Content check (before showing the client)

- [ ] Name, address, phone and WhatsApp number spelled exactly as the client wrote them
- [ ] WhatsApp link opens the right chat with the greeting text (tested on a phone)
- [ ] Phone link starts a call
- [ ] Hours correct, including Friday and holidays
- [ ] Every price checked line by line against the client's list, in MAD
- [ ] No leftover sample name, sample phone, sample review or sample price from the template (search the files for the template's sample business name)
- [ ] No invented testimonials. Only real, written, permitted ones
- [ ] Arabic text read by a native speaker; RTL layout checked
- [ ] Photos are the client's or licensed, compressed, with alt text
- [ ] Google Maps link points to the right pin

## 2. Technical check

- [ ] Opens well on a small phone (375px wide) and on a laptop
- [ ] Text readable (contrast), buttons big enough to tap, keyboard Tab reaches everything
- [ ] Page title and description set; Open Graph image if wanted
- [ ] `SITE_BASE_URL` set to the real domain before building
- [ ] HTTPS active on the final domain, no mixed-content warnings
- [ ] `www` and non-`www` both work (one redirects to the other)
- [ ] No broken links; 404 page acceptable
- [ ] Last check on a different phone/browser than yours

## 3. Payment and paperwork

- [ ] Contract signed (after lawyer review of the template)
- [ ] Final payment received
- [ ] Invoice/receipt given for each payment

## 4. Go live

- [ ] Upload / deploy the built folder
- [ ] DNS pointed; wait for propagation, then re-test on mobile data (not only your Wi-Fi)
- [ ] Google Business profile updated with the site link
- [ ] Instagram/Facebook bio link updated (help the client do it)

## 5. Handover to the client

- [ ] Domain registered in the client's name; login shared through a safe channel (not in a public chat group)
- [ ] Hosting account owner noted: ______
- [ ] A copy of the source files given (zip or repository access) after final payment
- [ ] One-page "how to ask for a change" note: what is included, how to message me, expected answer time
- [ ] Renewal dates written down: domain ______ , care plan ______
- [ ] Care plan started or declined in writing

## 6. Follow-up

- [ ] Day 3 after launch: message "Everything fine? Any correction?"
- [ ] Day 14: ask for a Google review of the **business** if they are happy, and for permission (written) to show the site in my portfolio
- [ ] Day 30: send the first small edit reminder if on a care plan
- [ ] Add the client to my tracker: what worked, how long it took, real hours spent (to adjust prices)
